# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please report it responsibly:

- **Email:** carlos.frias@hey.com
- **Do NOT** open a public GitHub issue for security vulnerabilities

I will acknowledge your report within 48 hours and provide a resolution timeline within 7 days.

## Security Measures

- **Secret scanning:** Enabled (GitHub native)
- **Push protection:** Enabled
- **Dependabot:** Enabled
- **No credentials in source code** — report any found

## Disclosure Policy

- Vulnerabilities disclosed after fix is released
- CVEs requested for significant vulnerabilities
- Credit given to reporters unless anonymity requested
